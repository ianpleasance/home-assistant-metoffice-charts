# Met Office Charts

Download weather chart images from the Met Office DataHub and display them in Home Assistant.

## Features

✅ **Official API** — Uses Met Office DataHub (DataPoint retired Dec 2025)  
✅ **Image Entities** — One per chart parameter in your order  
✅ **Local Files** — Saved to `/local/metoffice_charts/` for easy access  
✅ **Free Tier** — Compatible with 1000 images/day limit  
✅ **Configurable** — 5-1440 minute refresh intervals  

## Quick Start

1. **Get DataHub Account** — Register at [datahub.metoffice.gov.uk](https://datahub.metoffice.gov.uk/)
2. **Create Order** — Subscribe to Map Images, select your parameters
3. **Add Integration** — Enter API key and order ID
4. **Display Charts** — Use image entities in your dashboards

## Chart Types

Choose from rainfall, temperature, wind, pressure, cloud cover, visibility, and more. Each parameter in your DataHub order becomes an image entity.
